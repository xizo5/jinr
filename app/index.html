        麦克风没打开

        如果不是上面那条，通常是两层开关有一层没开。按顺序检查：

        ① 浏览器站点权限：点地址栏左侧的 🔒 / ⓘ 图标 → 麦克风 → 允许 → 刷新页面

        ② 系统总开关：Windows：设置 → 隐私和安全性 → 麦克风，打开「麦克风访问」和「允许应用访问你的麦克风」。安卓：设置 → 应用 → 浏览器 → 权限 → 麦克风

        iPhone：设置 → App → Safari → 麦克风 → 允许（用 Chrome/Edge 打开的请改用 Safari）

        从微信/QQ 里点开的链接：点右上角 ⋯ → 在浏览器打开

        改好后回来再按住说话；还不行就重开一次页面。
